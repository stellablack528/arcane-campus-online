# 第一学期第 1～5 周玩法

## 入学时代与世界包

创建角色时可选亲时代、哈利在校时代或汤姆·里德尔在校时代，默认哈利在校时代。时代选择随角色写入本地存档，重启后恢复。三个 JSON 世界包位于 `src/resources/story/worlds/`，由 TaleState 的 `storyforge.package/v1` 加载器和语义校验器读取；各包定义时代背景、同学与教授、教室／图书馆／礼堂场景，以及第一周的行动条件和后果。旧角色自动使用默认时代。

## 入口与时间

完成第一堂魔咒课后，从第一周周一的午餐时段进入学期循环；开场魔咒课计入已上课程与魔咒学数值。游戏日程由玩家行动推进，不受电脑时钟影响。每天依次经过早餐、上午、午餐、下午、晚餐、自由活动、夜间；周末没有课程。第五周结束后显示阶段总结，不自动开放未完成的后续学期。

## 行动与后果

- 上课需要到当天对应教室。每节课令相应学科数值 +5、声望 +1；缺课令声望 -3，并记录缺席。
- 饭点需要到大礼堂。按时吃饭令健康 +8；错过一餐令健康 -12。
- 夜间休息令健康 +5；熬夜令健康 -5。健康降到 0 会进入重伤状态，必须接受校医救治才能继续。救治后健康恢复到 35，声望 -4。
- 自由探索时，礼堂、图书馆、庭院和霍格莫德的互动令声望 +1；普通教室只提供场景反馈。移动地点本身不消耗时段。
- 自由活动时可从庭院接近禁林。TaleState 授权的剧情行动决定撤离、谨慎观察或深入；谨慎观察健康 -12、声望 +2，深入健康 -38、声望 +4。健康降到 0 时由巡夜教授发现并送医。禁林不提供永久死亡或删档结局。
- 第二至第五周开始时各有一次新的校园线索旁白；第二周图书馆、第四周庭院有对应探索反馈。
- 第一周周五上午魔咒课发生铜鸟失控：学会一定程度的漂浮咒后可尝试施咒，也可提醒教授并协助同学，或先保护自己。缺课会错过现场。首周在图书馆自由探索可独立发现借阅线索；事件后去礼堂自由探索，同学会依据当时的选择或缺席作出不同回应。先听回应再找到线索，也能返回礼堂继续谈。事件结果和线索保存在角色存档中。

状态保存在本地 `character_term_states` 表中，包含日期、时段、健康、声望、四门已开放学科、出勤、用餐、禁林选择与重伤状态。切换剧情后返回自由探索，会继续原有学期进度。

## 手动试玩

1. 完成新生入学和第一堂魔咒课。此时应显示第一周周一午餐，魔咒学 5、已上课 1 节。
2. 打开“场景”抽屉前往大礼堂，点中央“在礼堂按时吃饭”；下午按课表进入对应教室。
3. 晚上可在庭院选择进入禁林，比较“谨慎观察”“冒险深入”和“撤离禁林”；低健康时深入会进入救治分支。
4. 第一周周五上午前往魔咒教室。比较持续上课积累魔咒学后的施咒、魔咒学不足时求助、主动缺课三条路线；随后在图书馆查线索、礼堂听同学回应。
5. 关闭并重启游戏，用同一角色登录，检查时代、日期、健康、声望、学科数值与首周事件结果是否恢复。

当前三个时代包提供不同背景与 NPC，首周样板已进入 TaleState 行动运行时；第二至第五周目前仍共用基础日程与少量线索旁白，更丰富的分时代支线留待后续内容扩展。
