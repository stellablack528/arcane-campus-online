# “自己翻页的书”探索事件任务报告

## 玩家现在能玩什么

完成第一堂魔咒课后，玩家可去礼堂听罗温的传闻、去图书馆观察旧书、去庭院读喷泉刻字。三个地点可以往返，线索没有强制顺序；从任一地点触发事件，叙事会从玩家所在的场景开始。

找到旧书后，学过漂浮咒的角色能用它托起脆弱书页；玩家也可以请图书管理员米拉帮忙。读完后，玩家可回礼堂把故事讲给罗温、去庭院请弗立维教授收藏，或留在图书馆暂不公开。没有奖励物品，也不靠战斗结算；选择关乎一段被遗忘的善意应如何流传。完成后仍可自由探索，再次与对应人物交谈会得到不同回应。

## 代码与数据

- `turning_pages.json` 是独立的双语章节包，定义三个场景、调查动作、漂浮咒条件、非魔法路径和三种结局。章节使用现有 `StoryDelta` 提交 flag、NPC 记忆与亲密度。
- 剧情加载器和校验器照常加载该内容包；中央叙事流显示旁白、NPC 发言与可选行动。场景抽屉的移动会转为章节内移动；离开事件区域时可暂停，之后恢复。
- 恢复新章节时，从已完成的魔咒课状态继承 `levitation_mastered` 等角色级事实。事件自己的线索 flag 仍留在事件状态中。完成章节后，NPC 记忆、章节结局和场景由现有数据库事务保存，重启后可恢复。
- 联机连接存在时，事件输入交给本地剧情运行时；普通同场景发言仍交给校园聊天。当前版本的剧情判定与状态由玩家客户端负责，尚未升级为服务端权威裁决。

## 怎么试玩

1. 完成角色创建至第一堂魔咒课，练习并学会漂浮咒。
2. 去礼堂与罗温说话，或直接到图书馆调查旧书、庭院读喷泉刻字。
3. 在图书馆观察书，再试“用漂浮咒托起脆弱书页”；也可选择请米拉帮忙。
4. 读完后去想找的人所在的地点作决定。结束后再找罗温、教授或米拉对话，观察回应。

- 数据恢复测试覆盖跨章节继承学会漂浮咒的标记。

## 对最终 Agent 目标的意义

这次把可迁移的单位做成“场景、调查、条件、后果、人物记忆”的数据包。将来玩家输入新世界观时，生成器可以产出同类内容包，再经过校验器与确定性运行时执行。当前事件仍是人工编写的样例，尚不能根据任意世界观自动生成，也没有实现无限制的自然语言行动。
