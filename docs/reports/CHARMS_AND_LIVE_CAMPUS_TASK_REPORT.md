# 魔咒课与联机校园试玩版任务报告

## 玩家体验

完成分院后自动进入第一堂魔咒课。先练习挥杖与发音，再施展漂浮咒；成功后开放校园探索。玩家可以使用场景抽屉或输入“去图书馆”“去礼堂”“去庭院”移动，每处都有简短旁白。

打开校园联机服务后，同一场景的玩家可以在“地点”频道交谈。玩家移动后，旧场景不再收到他的消息；输入 `/owl 昵称 内容` 可给另一场景的在线玩家送信。到场和离场也会显示在中央叙事流。

## 实现

- `first_charms_lesson.json`：双语魔咒课。练习是施咒的前置条件，完成后写入 `levitation_mastered`、`main_story_complete`、`open_world_handoff_ready`。
- 分院末尾使用现有事务效果过渡到魔咒课；已完成分院的旧存档恢复后也能进入新章节。
- `CampusWireServer` 和 `CampusWireClient`：基于 Qt TCP 的 JSON 行协议。服务端按场景广播发言，并向指定在线玩家投递猫头鹰消息；单条消息设有长度限制。
- `ArcaneCampusLiveServer`：独立服务端程序，默认监听 `127.0.0.1:8888`。
- 客户端在进入自由探索时连接服务端，移动时同步场景。服务端不可用时仍能单人游玩。

## 本机试玩

1. 运行 `build/verify/ArcaneCampusLiveServer.exe`。
2. 分别启动两个 `build/verify/HogwartsOnline.exe`，让两个不同昵称的角色完成第一堂魔咒课。
3. 在同一地点的“地点”频道发言；让一人移动到图书馆，观察原地点的消息隔离。
4. 输入 `/owl 对方昵称 你想说的话`，检查跨场景投递。

局域网试玩时，服务端设置 `ARCANE_SERVER_BIND=0.0.0.0`；客户端设置 `ARCANE_SERVER_HOST=服务端局域网地址`。端口由双方的 `ARCANE_SERVER_PORT` 配置。请仅在可信网络中使用这版服务。

## 验证

- 主程序与独立服务端编译通过。
- CTest：10/10 通过。
- 双客户端回环测试覆盖同场景发言、跨场景隔离、猫头鹰投递。
- 完整主线测试覆盖“分院 → 练习 → 漂浮咒 → 自由探索”，也验证跳过练习不能施咒。

## 目前边界

这是一版小型可信联机试玩：服务端按客户端提供的昵称和场景路由消息。账号认证、断线续传、探索位置持久化及服务端剧情裁决尚未实现。现有数据库继续保存角色与主线状态。正式公网使用前，需要由服务端验证身份和行动权限。
