# Qt Creator 本地试玩

## 打开正确工程

用 Qt Creator 打开本仓库根目录的 `CMakeLists.txt`，选择 **Desktop Qt 6.10.1 MinGW 64-bit** Kit，构建并运行 `HogwartsOnline`。当前主界面以中央叙事流为主体，两侧功能是抽屉；如果仍看到旧版三栏校园主页，请检查 Qt Creator“项目 → 运行”中的可执行文件路径，再执行“构建 → 重新构建项目”。

## 自动存档

普通单人试玩无需 MySQL、`database.ini`、命令行导入或 DeepSeek API Key。首次启动会在系统的本地应用数据目录创建 `campus.sqlite`，之后创建角色、剧情选择、金币、背包和 NPC 记忆都写入同一份存档。退出后使用注册时的**用户名**和学院继续；角色昵称不是登录用户名。

如果设置了 `ARCANE_DB_CONFIG`，或程序运行目录中存在 `database.ini`，客户端会继续使用指定的 MySQL 开发库。连接失败会停在登录页并显示原因，避免无意中打开另一份空存档。MySQL 存档不会自动迁移到 SQLite；要继续原来的角色，请保留 MySQL 配置。

需要自行指定本地存档目录时，可在 Qt Creator“项目 → 运行 → 环境”设置 `ARCANE_LOCAL_SAVE_DIR`。默认情况下无需设置它。

## 从头游玩

点击“创建新生角色”，填写用户名、角色信息和魔杖线索。登记后中央叙事框会从对角巷开始；按选项进入奥利凡德魔杖店，之后完成购物、入学旅程、分院和第一堂魔咒课。学会漂浮咒后可到礼堂、图书馆、庭院调查自己翻页的书。想体验另一种结局，请创建新用户名。

联机试玩时，再单独启动 `ArcaneCampusLiveServer` 并打开两个客户端；它们默认连接本机 `127.0.0.1:8888`。本地存档与当前联机聊天服务仍是两个独立部分。
