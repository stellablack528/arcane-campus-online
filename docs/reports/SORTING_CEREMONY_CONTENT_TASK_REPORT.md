## 玩法内容

本章包含四个连续场景：

```text
黑湖渡船 → 礼堂前厅 → 分院帽前 → 学院长桌
```

玩家可以体验：

1. 与新生一起乘小船穿过黑湖，第一次从湖面看见城堡。
2. 罗温会根据此前列车旅程中的记忆和好感，表现为亲近的老朋友、见过面的同学或第一次正式认识的人。
3. 在礼堂前厅等待时，帮助过罗温搬箱子的玩家会触发专属回忆台词。
4. 分院帽读取角色档案中已经保存的学院，不让玩家重复选择或覆盖档案。
5. 格兰芬多、斯莱特林、拉文克劳和赫奇帕奇分别拥有独立的分院帽评价与长桌欢迎旁白。
6. 玩家在学院长桌坐下后完成章节，并解锁未来章节 `first_night_at_hogwarts`。

章节要求玩家已经完成 `journey_to_hogwarts`；不满足前置条件时，引擎会拒绝启动。

## 内容与代码实现

### 原生 v2 内容包

新增 `src/resources/story/chapters/sorting_ceremony.json`：

- 4 个场景；
- 7 个确定性剧情动作；
- 中英文标题、旁白、玩家行动和 NPC 对话；

- 使用 `complete_chapter` 完成本章；
- 使用 `unlock_chapter` 解锁 `first_night_at_hogwarts`。

所有状态变化均使用通用引擎已有白名单能力，没有新增章节专属 C++ 规则，也没有把内容判断写入 UI。
