# 通往霍格沃茨多章节任务报告

> 后续状态（2026-10-21）：分院仪式与自主探索交接已经接入生产主流程。下文保留本报告生成时“旅程止于霍格莫德”的阶段性范围。

## 交付结果

在不修改网络模块、不新增数据库迁移的前提下，通用剧情引擎已从“只接管对角巷”扩展为可编排的多章节主流程。玩家完成对角巷采购后，可以主动启程，并连续游玩至霍格莫德车站；章节、场景、NPC 记忆、好感、金币和背包继续使用现有事务存档与恢复能力。

## 玩家现在能玩什么

1. 在对角巷完成魔杖、书籍、校袍、魔药用品和宠物采购。
2. 回到街道后选择“前往国王十字车站”，正式离开对角巷。
3. 在国王十字检查车票、询问搬运工或跟随巫师家庭，寻找九又四分之三站台。
4. 在站台认识罗温·维尔；帮忙抬箱子会提高好感并形成永久记忆。
5. 登上霍格沃茨特快，与罗温分享糖果或安静看风景。
6. 列车旁白会读取对角巷买到的宠物，分别回应猫头鹰、猫或蟾蜍。
7. 中途退出后可从已保存场景恢复；罗温会根据之前的相遇和帮助改变招呼。
8. 抵达霍格莫德车站并跟随新生前往湖边，完成本章并解锁“分院仪式”。分院仪式本身是下一阶段内容，本次没有伪装成已可游玩。

所有动作既可点击建议选项，也可在中央叙事框输入已配置的中英文表达。

## 代码与架构改动

### 1. 通用跨章节契约

- 新增 `TransitionChapterEffect` 和 `StoryDelta::nextChapterId`。
- JSON 白名单新增 `transition_to_chapter`，Schema 同步更新。
- 校验器拒绝无效章节 ID、单个动作的多个章节跳转，以及同一动作同时跳场景和跳章节。
- 引擎只生成确定性的 Delta；运行服务在事务提交成功后才发出章节切换信号。
- 事件日志记录 `next_chapter`，便于审计剧情跳转。

### 2. 章节目录与战役编排

- `StoryChapterCatalog` 负责章节注册、单章内容校验及跨章节目标校验。
- `StoryCampaignService` 集中装配内置新生战役，控制器不再自行拼装每个章节。
- 对角巷仍复用原有唯一内容源，通过适配器进入目录；新旅程直接使用原生 v2 JSON。
- `CampusController` 通用化章节启动、恢复、叙事频道、位置和状态同步。

### 3. 内容包

- 新增 `journey_to_hogwarts.json`，包含 4 个场景和 10 个可执行剧情动作。
- 使用现有条件/效果表达 NPC 记忆、好感、宠物分支、章节完成和下一章解锁，没有把剧情规则塞回 UI 或控制器。
- 对角巷增加仅在采购完成后显示的启程动作；完成后仍允许继续探索，不强制传送。

### 4. UI 接入

- 地点面板识别国王十字、九又四分之三站台、霍格沃茨特快和霍格莫德车站。
- 角色状态面板显示各阶段的本地化旅程状态，并在旅途中隐藏课程信息。
- 新 NPC 罗温及所有新地点、状态均提供中英文显示文本。
- 中央叙事框继续是唯一剧情主体，按钮和自由输入都进入同一个 `StoryRuntimeService`。

### 5. 存档与数据库

- 没有修改 Schema，也没有新增迁移。
- 新章节复用数据库 v4 的 `(character_id, chapter_id)` 多章节状态、JSON 状态、乐观 revision、NPC 记忆和事件日志。
- 章节转换仍遵守“金币/背包/NPC/剧情状态全部成功才发布 UI”的事务边界。
- 登录恢复从只识别对角巷改为识别战役目录里的任意已注册章节。
